Ссылка на бота: https://t.me/bi_send_bot

Telegram бот отдела аналитики на момент написания документации используется несколькими отделами:

* Отделом аналитики для контроля запущенных на сервере задач, и их перезапуска без подключения к серверу при необходимости.
* PPC отделом для контроля еженедельного сбора данных по PPC проектам в Google BigQuery, и запуска пересбора данных по необходимости.
* Финансовым отделом для запуска задач по загрузке данных в доксы, которые используются финансовым департаментом.

Бота можно использовать как в приватном чате, так и добавлять в групповые чаты. На данный момент бот добавлен в 2 чата:

* Задачи на сервере (Alsey, Clarkson, Haruka)
* Ошибки при сборе данных по PPC проектам (Alsey, PPC TL, nlo)
