start - Запуск основной клавиатуры бота
server_manager - Запуск Server Manager
task_list - Запросить полный список настроенных на сервере задач
tasks - Запросить список задач, работа которых была завершена ошибкой
running_tasks - Задачи которые выполняются в данный момент
task_info - Запросить информацию по задаче, пример /task_info task_name
task_search - Поиск названия нужной задачи, по части её названия, пример /task_search als
run - Запустить задачу по её названию, пример /run task_name
chat_id - Запросить идентификатор чата
run_menu - Вызов меню запуска задач. Через данное меню можно запускать задачи название которых не превышает 64 символов
forget - Отключение задачи от мониторинга, пример /forget task_name 2020-09-01 10:00:00
unforget - Убрать задачу из списка отключённых от мониторинга, пример /unforget taskname
quite_tasks - Запросить список отключённых от мониторинга задач
autofix_disable - Отключение автофикса для конкретной задачи до указанного времени, пример /autofix_disable task_name 2026-09-22 18:00:00
autofix_enable - Убрать задачу из списка отключённых от автофикса (включить автофикс обратно), пример /autofix_enable task_name
autofix_disabled - Запросить список задач с отключенным автофиксом
reload - Команда для перезагрузки данных о ppc проектах в BigQuey, используется PPC TL, список сотрудников которые могут запускать данную задачу ограничен
ya_auth - Генерация токена Яндекс Директ, после команды надо указать логин т.е. /ya_auth yandex_login
stop - Остановка бота
update_db - Обновить данные в аналитических базах pup и pup_slave
get_users - Получить список всех пользователей
get_user_info - Получить информацию по пользователю, его id, привилегии и время последней активности
find_user - Поиск пользователя по запросу имени или фамилии
get_user_priv - Получить список привилегий пользователя
remove_priv - Удалить пользователю привилегии по имени и фамилии
remove_priv_by_id - Удалить пользователю привилегию по его id
add_priv - Добавить пользователю привилегию по имени и фамилии
add_priv_by_id - Добавить пользователю привилегию по его id
dir - Получить список файлов в указанной папке
get_file - Запросить файл с сервера по указанному пути
get_template - Запросить шаблон для постановки задач на отдел аналитики
help - Документация к боту
